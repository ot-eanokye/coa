# Logo Assets

This directory contains logo files used throughout the application.

## Files

- `COALOGO.jpg` - Certificate Of Analysis Management System logo used throughout the application and PDF reports

## PDF Logo

The logo is used throughout the application and in PDF documents generated by the system. To update it, replace `COALOGO.jpg` with another web-compatible image. Ensure it's in a web-compatible format (JPG, PNG).

Recommended size: 300x300px or larger (will be scaled down as needed)
