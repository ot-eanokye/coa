# Logo Assets

This directory contains logo files used throughout the application.

## Files

- `ernest-log.jpg` - Ernest Chemists Limited main logo (used on login and PDF reports)

## PDF Logo

The logo is used in PDF documents generated by the system. To add or update the logo for PDFs, replace the `ernest-log.jpg` file with your new logo. Ensure it's in a web-compatible format (JPG, PNG).

Recommended size: 300x300px or larger (will be scaled down as needed)
